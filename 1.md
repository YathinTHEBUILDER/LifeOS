# MASTER BUILD PROMPT — PERSONAL PLANNER / LIFE OS

You are the lead product engineer, software architect, UI/UX designer, and QA engineer responsible for building a production-quality personal planning and scheduling web application.

The application is a **personal productivity operating system** designed primarily for one user, but the architecture must support multiple authenticated users in the future.

The application must work beautifully on:

* Desktop/laptop browsers
* iPhone browsers
* iPhone Home Screen as an installable PWA

Do not treat the mobile version as a shrunken desktop website. Design the responsive experience intentionally for both form factors.

---

# 1. PRODUCT VISION

Build a personal planner that combines:

* Calendar
* Tasks
* Time blocking
* Projects
* Daily planning
* Habits
* Notes
* Focus sessions
* Productivity review

The core philosophy is:

> CAPTURE → PLAN → SCHEDULE → FOCUS → COMPLETE → REVIEW

The application should answer one question extremely well:

> "What should I be doing right now, and what should I do next?"

This is NOT intended to become an overloaded Notion clone.

The product should feel:

* Fast
* Calm
* Minimal
* Intelligent
* Personal
* Modern
* Extremely easy to use
* Information-dense without feeling cluttered

Avoid unnecessary gamification.
