# 8. RLS SECURITY AUDIT

This is CRITICAL.

Inspect every user-owned Supabase table.

Verify Row Level Security.

For every table determine:

* Is RLS enabled?
* Can an unauthenticated user read it?
* Can another authenticated user read it?
* Can another user modify it?
* Can another user delete it?
* Can a user insert records belonging to another user?
* Can a user manipulate IDs to access another user's data?

Test realistic attack scenarios.

Example:

User A creates task A.

User B attempts to query task A.

This MUST fail.

User B attempts to update task A.

This MUST fail.

User B attempts to delete task A.

This MUST fail.

User B attempts to create a task with User A's user_id.

This MUST fail.

Do not rely on frontend filtering for security.
